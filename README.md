
# Gift Shop Hub

A full-stack gift shopping application built with React, Tailwind CSS, Node.js, Express, and MongoDB.

## Features

- User Registration and Login
- User Profile
- Shop Listing and Product Browsing
- Shopping Cart and Checkout
- Order History
- Role-Based Access Control
- Admin Dashboard
- Shop, Product, User, and Order Management

## Project Structure

- `frontend/` - React frontend application
- `backend/` - Express backend API

## Setup

Install dependencies separately inside the frontend and backend folders.

Configure environment variables in a local `.env` file before starting the backend.
